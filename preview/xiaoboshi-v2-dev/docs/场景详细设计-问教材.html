PART A · 业务流程

问教材端到端业务流程

问教材承接的是教师围绕教材知识、学科概念、课标内容、课堂讲解对象的轻量提问。它的差异化不在「LLM 知道多少」，而在于把问题理解清楚、把教材依据组织清楚、把回答讲清楚——一句话原则：先保证回答有据可依，再追求讲得漂亮。

1场景定位与边界

问教材是小博士的知识解释场景：教师已经有一个关于教材/学科的问题，系统的职责是基于教材依据把它讲清楚，而不是找现成资源、也不是直接产出完整教学产物。一句话定位——「问知识、要讲解，来问教材」。

纳入与不纳入

维度问教材负责不在本场景
用户当前要什么对教材知识 / 概念 / 课堂讲解对象的理解找现成资源 · 生成完整产物 · 解题给答案
典型输入「光反应和暗反应有什么区别」「这页怎么讲」「找一份三角函数试卷」「出一份卷子」「这道题答案是什么」
系统产出有教材依据的结构化讲解（可二次加工成卡片）资源列表 · AI 生成的卷子/课件/教案 · 题目解析
不做什么不凭空声称「教材中指出」、不替代资源检索、不直接生成完整产物——只理解、检索教材依据、讲清楚。

与相邻场景的边界

问教材要划清的是「要理解知识」与「要现成资源 / 要新产物 / 要题目答案」之间的界：

相邻场景区别（它要什么）衔接关系
找资源要已有成品文件，而非知识讲解回答后「查看相关资源」可流出到找资源；找资源也可反向流入
出卷子 写教案 画导图要 AI 新生成产物，而非讲清知识「出几道练习题 / 生成导图」等后续动作 handoff 到对应场景（见 §6）
题目解析给出题目的答案/解法「这道题考哪个知识点、对应教材哪里」留在问教材；「答案/怎么做」转题目解析
易混的三条线① 考法分析（怎么考）留问教材，出题转出卷子；② 教学设计启发（怎么导入/活动建议）留问教材，完整教案转写教案；③ 题目知识点定位（考哪个点）留问教材，题目解析（答案/解法）转题目解析。详见 主文档 §2.2 意图识别。

覆盖范围：从全局路由命中问教材（或用户主动进入）开始，到一次有据回答呈现、提供二次加工与跨场景流转为止，包含正常链路与异常分支。

2端到端流程总览

一次完整交互由六层串起：路由层 → Agent 层 → 教材上下文层 → RAG 层 → 生成层 → 展示层。主线如下：

1

用户入口

点「问教材」 / 路由命中 / 从找资源等场景流入。

2

冷启动或带问题进入

无输入 → 教材选择器（不限教材 / 继续上次 / 选一本 / 勾选多本）；有输入 → 直接解析。

3

输入解析

识别学科、学段、知识主题、问题类型、输出深度、指代关系、是否有上传内容。

4

追问判断（克制）

主题缺失 / 指代无对象 / 图片识别不清时，才追问一轮；否则直接答。

5

教材上下文判断

指定教材 / 多本教材 / 上传内容 / 候选教材 / 通用知识，决定 RAG 范围与依据文案。

6

RAG 检索与可靠性判断

知识点召回 → 章节片段召回 → 重排 → 判断能否引用，不足则降级通用知识。

7

动态回答 + 依据 + 后续动作

按问题类型选结构 → 标注依据类型 → 给 2–4 个后续动作（部分 handoff）。

3前台交互层

3.1 场景入口

  • 用户主动点击首页 / 工作台「问教材」入口；
  • 在通用输入框输入带知识理解意图的句子，由全局意图路由命中问教材；
  • 从找资源、做课件等场景的相关入口流入，带着学科 / 主题上下文。

采用「左侧对话 + 右侧「这本教材」」的双栏工作台：右侧分教材身份栏 + 两个视图（教材依据 / 教材目录），顶部场景切换栏可切到其他场景。

3.2 冷启动教材选择器（无输入进入）

进入但还没提问时，展示教材选择器，四条路径并存：

路径含义后续
不限教材直接问不锁定版本，先答；依据标注为候选/通用随时可在顶部「选择教材」锁定
继续上次（登录态）按记忆里常看的教材打开，定位到上次章节资源篮/记忆驱动，登录可用
选择一本教材学段→学科→版本→册次逐级选定基于指定教材 RAG，依据=「基于：…」
勾选多本教材跨年级/跨版本综合复习或对比多本分别检索，依据=「已对照 N 本」

示例问题可点击直接发起一次提问（不限教材时先以候选/通用作答）。

3.3 输入、上传与累积上下文

输入框接受自然语言提问与截图/附件上传（教材页、讲义片段）。系统识别学科、学段并累积到会话上下文，使「这页怎么讲」「再深一点」等模糊跟进也能正确解析。上传内容优先级最高，识别不清时请用户重新上传或补文字，禁止猜测图片内容。

4意图路由层

全局意图路由综合动作词、知识词、附件类型、上下文判断主场景。与问教材直接相关的判定：

路由结果命中条件典型输入
命中问教材问概念/定理/原因/区别/课堂讲解对象；短知识点（如「三角函数」「光合作用」）默认进入「X 是什么 / 为什么 / 有什么区别 / 这页怎么讲」
不命中（找资源）找、下载、有没有现成资源「找 X 课件 / 下载 X 试卷」
不命中（题目解析）给出题干/选项/截图，要答案、解析、怎么做「这道题怎么做 / 答案是什么」
不命中（生成 / 通用）明确要生成产物，或非教学「出一份卷子 / 写教案 / 今天天气」
混合意图「知识 + 资源」（如「X 有哪些重点？有没有课件？」）先问教材回答重点，再把「查看相关资源」作为后续动作；「知识 + 生成」转生成场景。置信度低时轻量确认，不直接执行错误场景。详见 主文档 §2.2。

5内部处理层

5.1 输入解析

命中后把输入解析为后续可用的结构化信息：学科、学段/年级、知识主题、问题类型、输出深度、是否有指代（这个/这页/这道题）、是否有上传内容、是否需要追问。问题类型体系见 §7.2。

5.2 追问 / 澄清判断（克制）

只有缺失信息会影响准确回答时才追问，最多一轮；否则直接答。

当前情况是否追问处理方式
主题明确、学科可稳定推断否直接进入回答
主题缺失（如「帮我讲一下」）是追问学科 + 知识主题，给结构化选项并保留自由输入
有指代但无对象（「这个怎么证明」无上文/附件）是请上传截图或补充文本
要求按某版教材但未选具体教材是引导打开教材选择器
图片识别不清是请重新上传清晰图片或补文字，不猜图

5.3 教材上下文判断

决定本轮回答基于什么，并直接决定依据文案（见 §7.3）。优先级：

  • 上传内容 优先级最高；
  • 已选一本教材 → 基于指定教材检索；
  • 选了多本教材 → 分别检索，跨教材对照；
  • 未指定但能识别学科学段 → 候选教材，不得断言某一具体版本；
  • 无可靠上下文 → 通用学科知识，必须标注。

5.4 RAG 检索与可靠性判断

检索是确定性工程 + 向量检索，不交给 LLM 编造出处：query rewrite → 分层召回（先知识点/目录定位，再章节片段）→ 多本教材分别检索 → 片段重排 → 可靠性判断（能否引用，否则降级通用知识）→ 引用清洗（把 v3 末尾来源编号转成结构化 citation）。

依据可追溯 ——「凭空不答」教材版本、章节、页码、原文摘录必须来自检索返回。可靠性不足时降级为通用知识回答并明示，绝不强行引用。这是问教材区别于普通 AI 问答的关键。

5.5 回答生成与依据

先给直接答案，再按问题类型选结构（见 §7.2）；结论必须能被引用片段支撑；明确依据类型；默认控制在教师可快速阅读的长度，要求详细时再展开；结尾给 2–4 个后续动作。

5.6 后续动作编排

留在问教材内（展开解释、举例、生成知识卡片）或 handoff 到其他场景（查看相关资源、生成导图、出练习题）——见 §6。

6后续动作与跨场景流转

问教材回答完成后，自然衔接下一步教学动作。动作必须承接当前答案与依据，不脱离原回答重新发散：

动作去向说明
展开解释 / 举个例子问教材继续围绕当前依据讲深，留在本场景
生成知识卡片问教材二次加工把当前回答整理成卡片，继承本回答依据，可嵌入课件 / 供学生复习
查看相关资源找资源带上知识主题、学科、学段
生成知识导图画导图带上当前回答摘要与依据
出几道练习题出卷子带上知识主题、难度、教材
handoff 含义切换到另一个场景只改右侧面板，左侧对话线索不中断——用户感知为「同一位助手继续」。知识卡片是当前回答的二次加工，不是新一轮无依据生成。详见 主文档 §2.4 会话与多轮迭代模型。

PART B · 回答与依据

回答结构与依据透明

问教材的回答不是「一种长相」，而是按问题类型动态选结构，并把「基于什么作答」明明白白地标出来。本节定义问题类型体系、依据类型与文案、引用溯源与切换教材重答。

7.1核心交互原则

遵循「一条会话贯穿」：右侧「这本教材」面板提供教材依据（跟随回答）与教材目录（翻书）两个视图；回答正文用上标 [1][2] 关联右侧引用卡片，点击可打开教材原文扫描页。两条透明原则贯穿始终：

①

依据透明

每条回答都说明基于什么——指定教材 / 上传内容 / 候选教材 / 通用知识 / 多本教材，不让用户误会来源。

②

不确定性透明

候选教材、通用知识、识别不清都明说；能引用才显示教材出处，不足则降级并标注。

7.2.1 知识卡片：每类回答的二次加工

每个回答都可一键「生成知识卡片」——把当前回答浓缩成一张可嵌课件 / 供学生复习的卡片，继承该回答的依据（不另起一轮无依据生成）。卡片结构随问题类型自动适配，从回答 blocks 提炼：

来源回答含卡片呈现适用类型（举例）
对比表（table）紧凑对比表对比分析、易错辨析、考法分析
原因/机制/脉络链（chain）编号步骤流原因解释、原理机制、知识脉络
分点（points）要点清单概念、归纳、应用、教材解读、课堂讲解、教学设计、考法
note / pitfall卡片底部「记忆 / 易错」条全部
basis 依据卡片页脚溯源条（绿色可溯 / 黄色通用）全部

卡片标题取问题主体 + 类型标签；点击「生成知识卡片」弹出卡片模态，支持「复制文本 / 存入我的内容」。这样保证「回答按 17 类、卡片也按 17 类」一一对应，不再出现回答细分而卡片只剩少数模板的断层。

7.3依据类型与文案

依据类型由 §5.3 教材上下文判断决定，直接对应用户可见文案，且真实反映来源——不把系统推断说成用户已指定，不把通用知识说成教材内容。

依据类型可溯源展示文案
指定教材是（绿色）基于：人教版 · 高中生物 · 必修1 · 第 X 章
上传内容是（绿色）根据你上传的教材页整理
多本教材是（绿色）已对照 3 本教材内容，分别标注出处
候选教材否（黄色）可能关联教材内容。选择具体版本后可获得更贴合课本的解释
通用知识否（黄色）当前按通用学科知识回答。选择教材后可获得更贴合课本的解释
🛡 指定 / 上传 / 多本 → 绿色可溯条 + N 处引用 ⚠ 候选 / 通用 → 黄色提示条，不声称教材原文

7.4引用溯源与教材原文

右侧「教材依据」视图显示引用卡片，每条含 来源（版本·学科·册次）、定位（章节·页码）、原文摘录，点击可打开教材原文扫描页。citation 对象：

关键防护① v3 的原始来源编号（如 ####0,2）不能直接暴露，需解析成结构化 citation；② 候选 / 通用回答的引用标为「可能关联」，不作为教材原文依据；③ 回答中出现的每个引用编号都必须能在 citations 集合内找到（防幻觉校验）。

7.5切换教材与重新回答

切换教材不静默改写旧答案：切换后保留历史回答、落一条分隔，并提供一个显式的「按新教材重新回答」入口，点击后基于新教材范围重新检索作答，旧答案仍在历史里可回看。

系统架构、里程碑与实现状态

问教材里 LLM 不应凭记忆讲教材。真正形成可信度的是教材库、目录、原文、上传内容和可追溯引用。LLM 只做三件事：把问题理解清楚、把依据组织清楚、把回答讲清楚。约 80% 工作量在教材数据与 RAG 底座，系统提示词是最薄、最后、最易改的一层。一句话原则：先把数据和 RAG 做实，再写 Agent 和提示词。

9异常分支与关键原则

9.1 异常与降级分支

异常触发处理
未登录登录态不可用不影响通用问教材；记忆、继续上次、个性化不可用
图片识别不清OCR 置信度低请重新上传或补文字，不编造
知识库无匹配检索不到可靠片段降级通用知识回答并标注
教材版本差异版本影响答案先答候选/通用，再引导选具体教材
上传与已选教材冲突上传页与当前教材不一致以上传内容为上下文，提示可能差异
来源编号未解析出现原始 ####0,2前端隐藏，后端解析为 citation
引用不支撑结论可靠性低删除引用或降级通用回答
用户要找资源/生成产物「有没有课件」「出卷子」handoff 到对应场景

9.2 关键原则回顾

①

依据透明

每次回答都说明基于什么，指定/上传/多本可溯，候选/通用明示不确定。

②

引用可追溯

教材依据必须能回链教材原文，出处不由 LLM 编造。

③

追问克制

最多一轮，能答先答；缺最小必要信息时才追问。

④

后续动作不断线

回答后自然衔接资源、导图、练习、卡片；卡片继承原依据，不重新发散。
