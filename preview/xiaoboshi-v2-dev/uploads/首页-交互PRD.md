# 首页 — 交互 PRD

> 版本：v1.0 · 2026-06-30
> 状态：初稿
> 原型基线：`AI 教学助手/homepage.jsx` 方案A（对话优先）

---

## 1 页面定位

首页是小博士的默认落地页，核心任务是**让教师尽快开始一个新需求**。教师可以直接输入自然语言描述，也可以点击场景入口直接进入。

首页不承担内容消费、历史管理等职能——这些由侧边栏导航进入的独立页面承担。

## 2 页面结构与信息层级

首页从上到下的信息层级：

### 2.1 品牌问候

- Bot 头像（带光晕），居中
- 主标题："老师好，今天想准备点什么？"
- 副文案："说出你的需求，我会从**学科网资源库**出发，陪你一起完成。"

### 2.2 示例引导（老师们在问）

- 标签："✦ 老师们在问"
- 桌面端展示 5 条示例 query，移动端展示 3 条
- 每条是可点击的 pill 按钮，品牌浅色背景
- **点击行为**：将示例文本作为用户输入提交，走意图路由判断，进入对应场景
- 示例内容覆盖不同场景（找资源、出卷子、做课件、写教案、画导图、问教材、改作业），从数据池中选取

### 2.3 智能输入框（SmartInput）

输入框是首页的核心交互组件，大尺寸居中。

**基础功能：**

- 多行文本输入，最大 5 行，超出后内滚动
- Enter 提交，Shift+Enter 换行
- 附件按钮：支持上传多个文件（上限待技术评审），已选文件显示为可移除的 chip
- 发送按钮「开始 ➤」：有内容时品牌渐变色，无内容时灰色禁用

**Ghost Placeholder 轮播：**

- 输入框为空时，placeholder 显示真实教师 prompt 示例，每 3.4 秒轮播切换
- 内容来源：后端配置 + 根据教师记忆个性化（已登录时优先展示与教师学科/学段匹配的示例）
- **Tab 填入**：输入框为空时按 Tab 键，当前显示的 placeholder 文本填入输入框，焦点留在输入框，教师可修改后提交
- Tab 填入提示：输入框底部显示 `[Tab] 填入示例`（仅输入框为空时显示）

**场景标识：**

- 输入框底部左侧显示 "✦ AI 自动识别场景" 标签，告知教师输入后系统会自动判断场景

**提交行为：**

- 输入文本提交后，走意图路由判断（规则层 → 场景 Agent 边界判断 → 独立路由 Agent），进入对应场景工作台
- 如果意图识别为需要立即登录的场景（出卷子），且用户未登录，弹出登录弹窗，登录后继续流程

### 2.4 场景入口

7 个场景以 pill 按钮形式横排展示，自动换行。每个 pill 包含：

- 场景专属 icon（圆形色块背景）
- 场景名称
- badge（可选，如「做课件」显示「互动」标签）

**排列顺序**：找资源 / 出卷子 / 做课件 / 写教案 / 问教材 / 画导图 / 改作业

**点击行为**：直接跳转到对应场景工作台，不经过意图路由判断。

**登录拦截**：

- 出卷子：未登录时点击，弹出登录弹窗，登录后进入出卷子场景
- 其他场景：未登录可直接进入

**交互效果**：hover 时上浮 + 场景色阴影 + 边框变色

### 2.5 记忆面板 / 登录引导

此区域根据登录状态显示不同内容：

#### 2.5.1 未登录：登录引导（LoginHook）

虚线边框卡片，左右布局：

- 左侧：
	- 标签 pill："✦ 登录解锁「小博士记忆」"
	- 标题："登录后，小博士会记住你、越用越懂你"
	- 三个价值点（icon + 文字）：
		- 记住你的学科、学段与版本偏好
		- 一键续作上次的课件、试卷与教案
		- 同步你的收藏与下载，随处可取
- 右侧：
	- 「登录 / 注册 →」按钮（品牌渐变色）

#### 2.5.2 已登录：记忆面板（MemoryPanel）

**两种状态：展开（默认）和关闭（完全隐藏）。** 关闭状态通过 localStorage 持久化，无中间收起态。

**展开态结构：**

- **头部**：品牌浅色背景
	- icon + "小博士还记得你"
	- 副文案："从你的创作与收藏中学习 · 记忆更新于 {时间}"
	- 「管理记忆」按钮 → 跳转「我的记忆」页面
	- 关闭按钮（×）→ 关闭面板，持久化

- **主体**：左右两栏（移动端上下堆叠）
	- 左栏（1.15fr）：
		- summary 文字（200-300 字自然语言描述）
		- tags 展示（学科/学段/版本/难度/常做等，key-value pill 形式）
		- stats 统计（课件/卷子/教案/收藏/下载的数量，从业务 DB 聚合，不属于记忆模型）
	- 右栏（0.85fr）：
		- "继续上次创作" 标题 + 「我的内容 →」入口
		- 最近 3 条创作记录（场景 icon + 标题 + meta + 时间），点击恢复创作

**关闭后：**

- 该区域完全不渲染，首页直接从场景入口跳到权威背书条
- 教师可通过侧边栏「我的记忆」查看记忆内容
- 侧边栏「我的记忆」导航项旁显示更新标记（当记忆有变化时）

### 2.6 权威背书条（AuthorityStrip）

居中展示，用于建立产品可信度：

- 引导文字："小博士的每一份生成，背后都有学科网资源库支撑"（左右装饰线 + 盾牌 icon）
- 四格数据条（带边框卡片）：
	- 2000万+ 精品资源
	- 20 年 教研沉淀
	- 三审三校 质量把关
	- 全学段 学科覆盖
- 底部免责声明："AI 内容仅供教研参考，请结合实际教学进行调整"

## 3 登录状态与行为差异

### 3.1 两种全局状态

| 区域 | 未登录 | 已登录 |
| --- | --- | --- |
| 输入框 | 正常可用 | 正常可用 |
| 场景入口 | 出卷子点击弹登录窗，其他正常进入 | 全部正常进入 |
| 记忆面板位置 | LoginHook（登录引导） | MemoryPanel 或空（面板已关闭时） |
| 侧边栏导航项 | 我的记忆/我的内容/资源篮点击弹登录窗 | 正常进入对应页面 |
| 侧边栏历史对话 | 显示登录引导卡片 | 显示对话列表 |
| 侧边栏底部 | 「登录/注册」按钮 | 头像 + 姓名 + 学科 |

### 3.2 场景级登录限制

三档策略，覆盖所有场景：

| 登录要求 | 场景 | 触发点 | 登录后行为 |
| --- | --- | --- | --- |
| 立即登录 | 出卷子 | ① 点击场景 pill → 弹登录窗 ② 输入框提交 → 意图识别为出卷子 → 弹登录窗 | 登录后继续进入出卷子场景 |
| 5 轮对话后 | 做课件、写教案、画导图、改作业、问教材 | 第 5 轮对话时弹出登录窗 | 登录后继续当前对话 |
| 操作触发 | 找资源 | 点击下载时弹出登录窗 | 登录后执行下载 |

## 4 侧边栏（LeftRail）

侧边栏是全局导航组件，首页和四个独立页面共享。

### 4.1 桌面端

- 默认展开，宽度 252px
- 可完全收起（侧边栏隐藏），收起后左上角显示两个按钮：展开菜单 + 新对话
- 展开/收起状态 localStorage 持久化，跨页面保持

### 4.2 移动端

- 默认隐藏，顶栏左侧汉堡按钮触发
- 从左侧滑出抽屉，宽度 min(300px, 84vw)
- 带半透明遮罩层（点击关闭）+ 毛玻璃模糊

### 4.3 侧边栏结构（从上到下）

**① 品牌区**

- Bot 头像（40px，带光晕）+ "AI 小博士" + "你的备课教学助手"
- 收起/关闭按钮（桌面端为收起 icon，移动端为 × 关闭）

**② 新对话按钮**

- 全宽按钮，品牌渐变色背景，白色文字 "＋ 新对话"
- 点击回到首页并清空输入框

**③ 主导航**

四个导航项，当前页面高亮（品牌浅色背景 + 品牌色文字）：

- 我的记忆（✦ icon，品牌色强调）→ 跳转「我的记忆」页面
- 我的内容 → 跳转「我的内容」页面
- 资源篮（显示数量角标，如 "资源篮 · 3"）→ 跳转「资源篮」页面
- 历史对话（仅桌面端收起时显示，展开时由下方对话列表承担）

未登录时，我的记忆/我的内容/资源篮点击弹出登录窗。

**④ 历史对话列表（仅展开态）**

- 小标题 "历史对话" + 「全部」按钮（跳转「历史对话」页面）
- 已登录：按时间倒序展示对话列表，每条显示场景 icon + 标题 + 时间 + 最后一句摘要，点击恢复对话，可滚动
- 未登录：显示登录引导卡片 "登录后查看历史对话 / 你的每一次创作都会自动保存"

**⑤ 账号区（底部固定）**

- 已登录：头像圆形（姓氏）+ 姓名 + 学科标签，点击弹出浮层菜单
	- 菜单项：外观切换（浅色/深色分段控件）/ 退出登录
	- 未来预留：建议与反馈 / 帮助 / 设置
- 未登录：「登录 / 注册」按钮（品牌浅色背景）

### 4.4 外观切换

- 位于账号菜单浮层内
- 分段控件：浅色（☀）/ 深色（🌙）
- 切换即时生效，全局生效

## 5 独立页面

以下四个页面有独立 URL，与首页共享侧边栏布局，右侧内容区替换。

### 5.1 我的记忆（MemoryPage）

记忆系统的用户管理界面，教师可查看、编辑、删除小博士学到的内容。

**页面头部：**

- icon + "我的记忆" 标题
- 副文案："小博士从你的使用中学到的内容 · 你可以随时编辑或删除"
- 「清空全部」按钮（危险操作，需二次确认）

**四个区块：**

**① 小博士眼中的你**

- summary 自然语言文字（200-300 字）
- 更新时间显示

**② 教学画像**

- tags 以 pill 形式展示（key-value，如 "学科 → 数学"）
- 每个 tag 可点 × 移除
- 提示文字："自动推断 · 点 × 移除"

**③ 记忆条目**

- entries 列表，每条包含：
	- icon + 记忆描述文字（如 "常用人教版教材"）
	- 推断依据（如 "近 30 天 25 次创作中 23 次选择人教版"，带 ✦ icon）
	- 开关（on/off，关闭后该条记忆不再用于预填和推荐）
	- 删除按钮
- 统计提示："N 条生效 / 共 M 条"

**④ 记忆来源**

- stats 统计展示（课件/卷子/教案/收藏/下载的数量）
- 数据来源：业务 DB 聚合，非记忆模型

**底部隐私提示：** "🛡 记忆仅用于改善你的创作体验，可随时关闭或清空。"

**清空后空态：** icon + "记忆已清空" + "小博士会在你继续使用的过程中，重新学习你的偏好。"

### 5.2 我的内容（WorksPage）

教师的内容资产库，整合两类来源：AI 生成 + 学科网下载。

**页面头部：**

- icon + "我的内容" 标题
- 副文案："你的全部教学资料 · AI 生成与学科网下载，共 N 份"

**筛选与视图：**

- 来源筛选 pills：全部 / AI 生成 / 学科网下载
- 视图切换：列表（默认）/ 卡片，localStorage 持久化

**列表视图（每行）：**

- 场景 icon + 标题 + 类型 badge（试卷/课件/教案/思维导图…）
- meta 信息（版本·年级·难度·页数等）
- 来源标签（AI 生成 / 学科网下载，不同颜色）
- 时间 + 状态（草稿标记）
- 操作按钮：预览 / 下载 / 继续（AI 生成）或 打开（学科网下载）

**卡片视图：**

- 自适应网格（min 280px），每张卡片包含：预览色块 + 类型 badge + 来源标签 + 标题 + meta + 操作按钮

**点击行为：**

- AI 生成的内容：进入生成该资料的历史对话记录，定位到生成位置，右侧场景区打开该份资料
- 学科网下载的内容：打开找资源场景，右侧场景区显示该份资料的预览

**空态：**

- icon + "还没有内容"
- 说明文字："和小博士对话生成课件、试卷、教案，或在找资源中下载，都会出现在这里。"

### 5.3 历史对话（HistoryPage）

教师与小博士的所有对话记录，时间线展示。

**页面头部：**

- icon + "历史对话" 标题
- 副文案："你与小博士的每一次对话都已保存 · 共 N 段，点击任意一条继续"

**时间线布局：**

- 左侧竖向轴线，按时间分组（今天 / 昨天 / 3 天前 / 上周 / 更早…）
- 每组有时间节点标记（品牌色圆点）+ 分组标签 + 该组对话数
- 每条对话卡片：场景 icon + 标题 + 最后一句对话摘要
- 点击恢复对话（进入对应场景工作台，加载历史对话上下文）

**空态：**

- icon + "还没有对话记录"
- 说明文字："和小博士的每一次对话都会自动保存在这里，随时可以继续。"

### 5.4 资源篮（BasketPage）

跨场景收集的资源临时中转站，和学科网资源篮数据打通。

**定位**：临时购物车，不是持久收藏夹。

**数据来源**：仅在「找资源」场景中通过"加入资源篮"操作产生。和学科网主站资源篮数据双向同步。

**页面头部：**

- icon + "资源篮" 标题
- 副文案（有资源时）："已收集 N 份资源 · 可一并下载，或送去出卷 / 备课"
- 操作按钮：「清空」+「打包下载 N 份」（品牌色）

**资源列表（每行）：**

- 类型 icon（文档/视频/专辑，不同颜色标签）
- 标题 + 类型 badge + meta 信息
- 下载按钮 + 移除按钮

**下载与清空逻辑：**

- 单份下载：下载完成后自动移除该条
- 打包下载：下载完成后清空全部
- 手动移除：点击移除按钮移除单条
- 手动清空：点击清空按钮清空全部

**操作边界**：小博士资源篮只支持查看 / 下载 / 移除三个操作，复杂管理功能（移动到文件夹、分享等）留在学科网主站。

**空态：**

- 插画 icon + "资源篮还是空的"
- 说明文字："在「找资源」里预览任意文档或视频，点**加入资源篮**，就会出现在这里，随时取用。"
- 「去找资源」按钮 → 进入找资源场景

## 6 登录弹窗（LoginModal）

全局模态弹窗，由各处登录触发点统一调起。

### 6.1 触发条件

- 未登录点击出卷子场景 pill
- 未登录输入提交后意图识别为出卷子
- 未登录点击侧边栏我的记忆/我的内容/资源篮
- 做课件/写教案/画导图/改作业/问教材场景第 5 轮对话时
- 找资源场景点击下载时
- 未登录点击首页 LoginHook 的登录按钮
- 未登录点击侧边栏底部登录按钮
- 未登录点击侧边栏历史对话区域登录引导

### 6.2 弹窗结构

- 遮罩层（半透明 + 毛玻璃模糊），点击关闭
- 右上角关闭按钮
- 内容：
	- Bot 头像（居中）
	- 标题："登录 AI 小博士"
	- 副文案："登录后即可使用记忆、历史对话与作品管理"
	- 手机号输入框
	- 验证码输入框 + 「获取验证码」按钮
	- 「登录 / 注册」按钮（品牌渐变色，全宽）
	- 三个权益点：小博士记住偏好 / 历史对话云端同步 / 创作有据可依
	- 底部协议文字："登录即代表同意《用户协议》与《隐私政策》"

### 6.3 登录后行为

登录成功后，关闭弹窗，**回到触发登录前的操作并继续**：

- 从场景入口触发 → 进入对应场景
- 从意图识别触发 → 继续路由判断，进入对应场景
- 从侧边栏导航触发 → 进入对应页面
- 从对话轮次触发 → 继续当前对话
- 从下载触发 → 执行下载

## 7 响应式策略

### 7.1 断点定义

- 桌面端：≥ 900px
- 移动端：< 900px（含平板竖屏和手机）

### 7.2 关键差异

| 组件 | 桌面端 | 移动端 |
| --- | --- | --- |
| 侧边栏 | 固定侧边栏，可收起 | 汉堡抽屉 |
