## 1. 场景定位与流程边界

找资源是小博士的「已有资源检索」场景，对应学科网作为资源聚合平台的底座能力。用户的核心诉求是从学科网已有成品资源中，快速找到贴合自己班级学情的文档、视频、成套专辑，并据此收藏、下载，或直接流转到生成类场景。

它和问教材的分工是三分法里的两端：

| | 找资源 | 问教材 |
| --- | --- | --- |
| 用户当前要什么 | 已有成品资源 | 对知识点的直接理解 |
| 典型输入 | 「找一份三角函数试卷」「下载光合作用课件」 | 「三角函数是什么」「这页怎么讲」 |
| 系统产出 | 检索整理出的资源列表 | 结构化知识回答 |
| 与对方的关系 | 回答底部「查看相关资源」可从问教材流入 | 资源不合适时「直接生成」可流出到生成场景 |

两者前后衔接，不互斥。本文档覆盖范围：**从全局路由命中找资源（或用户主动进入找资源）开始，到一次检索结果呈现并提供资源操作与跨场景流转为止**，包含正常链路与异常分支。

## 2. 端到端流程总览

找资源一次完整交互同样由前台交互层、意图路由层、内部处理层三段组成。主线如下：

```text
用户入口（点「找资源」/ 路由命中 / 从问教材「查看相关资源」流入）
    │
    ▼
冷启动或带需求进入
    │
    ├─ 无输入 ──▶ 冷启动面板（个性化示例 / 热门检索 / 分类示例）
    └─ 有输入 ──▶ 直接进入检索
    │
    ▼
全局意图路由 ──未命中找资源──▶ 其他场景 / 通用问答兜底
    │ 命中找资源
    ▼
检索意图解析（资源形态·学科·学段·版本·类型·难度·主题）
    │
    ▼
追问/澄清判断 ──需缩小范围（设想）──▶ 一轮追问 ──放弃──▶ 用累积上下文先给一批
    │ 信息充分
    ▼
多源检索与排序（学科网库 / 我的内容 / 资源篮）→ 冻结为一轮 round
    │ 检索中
    ▼
结果分轨呈现（全部 / 文档 / 视频 / 专辑 + 来源标签 + 筛选项）
    │
    ├─ 资源操作：预览 / 播放 / 看专辑 / 收藏入篮 / 下载
    ├─ 追加检索：每轮结果冻结可回看（"给你了就是你的"）
    └─ 跨场景流转：送去出卷子 / 生成教案 / 做课件（资源不合适也能直接生成）
```

下面按环节拆解。

## 3. 前台交互层

### 3.1 场景入口

进入找资源有三条路径：

- 用户主动点击首页「找资源」入口；
- 用户在通用输入框输入带资源检索意图的句子，由全局意图路由命中找资源；
- 从问教材回答底部「查看相关资源」流入，带着上一轮的学科/主题上下文进入。

三条路径汇合后进入同一套内部处理链路。找资源采用「左侧对话 + 右侧结果舞台」的双栏工作台形态：用户在左侧用一句话描述需求，右侧呈现冻结的结果集，顶部场景切换栏可切到其他场景。

### 3.2 冷启动面板（无输入进入）

当教师进入找资源但还没有任何输入时，展示冷启动面板，引导用户用一句话描述需求，并说明结果会涵盖文档、视频、成套专辑三类。面板内容随登录态分化：

| 登录态 | 顶部横幅 | 推荐区 | 分类示例 |
| --- | --- | --- | --- |
| 已登录（有记忆画像） | 已结合记忆（如人教版·七年级·数学）推荐 | 「为你推荐」——按画像挑选 | 贴合你的班级 / 你常找的视频 / 成套备课专辑 |
| 未登录 | 提示登录后推荐更懂你 | 「热门检索」——大家都在找 | 文档（教案/课件/卷子）/ 视频（实验/微课）/ 专辑（成套合集） |

冷启动示例和热门词均可点击直接发起一轮检索。

### 3.3 输入与累积上下文

输入框接受自然语言需求（「人教版七年级上《有理数》同步练习，中等偏上」「2025年云南昆明 中考化学试卷」）。系统会从输入中识别学科、学段和资源形态，并把识别到的学科/学段**累积记忆**到当前会话上下文，使后续的模糊追问（「难度再高一点」「只要含答案的文档」）也能正确解析。

## 4. 意图路由层

全局意图路由是所有场景之前的前置分发层，综合动作词、资源词、学科词、附件类型、上下文历史判断主场景。

与找资源直接相关的路由判定：

| 路由结果 | 命中条件 | 典型输入 |
| --- | --- | --- |
| 命中找资源 | 含找、下载、有没有、资源、试卷、课件等检索意图 | 「找一份三角函数试卷」「下载光合作用课件」 |
| 不命中（生成产物） | 明确要求生成课件、教案、卷子、讲义 | 「生成一份三角函数课件」 |
| 不命中（问教材） | 问概念、定理、原因、区别、教材内容理解 | 「三角函数是什么」 |
| 不命中（通用兜底） | 非教学、闲聊、无法判断 | 「今天天气怎么样」 |

场景优先级上，找资源（明确资源检索）排在明确文件处理、明确生成类之后，问教材、方法指导之前。混合意图中，「知识 + 资源」（如「三角函数有哪些重点？有没有相关课件？」）先由问教材回答重点，再提供相关资源入口——即先问教材、后找资源衔接。

本文档从「命中找资源」之后接管。

## 5. 内部处理层

### 5.1 检索意图解析

命中找资源后，内部解析不再判断「是不是要找资源」，而是把需求转化为多源检索所需的结构化条件：

| 解析要素 | 用途 | 来源 |
| --- | --- | --- |
| 资源形态 | 决定结果分轨（文档 / 视频 / 专辑 / 全部混合） | 关键词识别：含「专辑/合集/套/打包/资源包」→ 专辑；含「视频/实验/研修/示范课/微课」→ 视频；否则全部混合 |
| 学科 | 限定检索范围 | 从输入识别，识别不到则取累积上下文 |
| 学段/年级 | 限定检索范围 | 从输入识别，识别不到则取累积上下文 |
| 版本 | 筛选条件 | 输入或筛选器（人教版/北师大版/通用…） |
| 资源类型 | 筛选条件 | 同步练习/单元测试/微课·学案/专项突破/教学课件… |
| 难度 | 筛选条件 | 基础/中等/拔高 |
| 知识主题 | 检索核心对象 | 输入中的知识点或《书名》 |

解析结果驱动一轮检索的过滤、混排和排序。

### 5.2 追问/澄清判断（设想）

> 原型当前对模糊输入采取「先用累积上下文给一批结果，不打断」的策略，并未实现主动追问。以下为对标问教材追问引擎的设计设想。

找资源的追问同样应克制：默认先给结果，只有当需求宽到结果噪声过大、可能浪费用户翻找成本时，才发起一轮澄清。

| 当前情况 | 是否追问（设想） | 处理方式 |
| --- | --- | --- |
| 学科+学段+主题可提取（「人教版七上有理数同步练习」） | 否 | 直接检索 |
| 仅资源形态明确但范围极宽（「找点试卷」） | 是 | 一轮补齐学科/学段，提供选项 + 我自己输入 |
| 模糊跟进（「难度再高一点」「只要含答案的」） | 否 | 用累积上下文 + 新条件，直接出新一轮 |
| 完全无法识别意图 | 是 | 回到冷启动式引导 |

追问原则与问教材一致：最多一轮、动态生成选项、保留自由输入、放弃补全则用现有上下文先给一批。

### 5.3 多源检索与排序

检索从三个来源取数，构成一轮混合结果：

| 来源 | 含义 | 排序权重 |
| --- | --- | --- |
| 我的内容 | 登录用户自己上传/拥有的资源 | 最高（排最前） |
| 资源篮 | 用户已收藏进资源篮的资源 | 次高 |
| 学科网 | 学科网资源库的公共成品资源 | 基础 |

处理逻辑：按资源形态决定文档/视频/专辑的混排比例（如「全部」默认 2 专辑 + 8 文档 + 3 视频，单轮上限约 14 项）；按学科/学段过滤，过滤后为空时逐级放宽（先放宽学段，再放宽学科）保证不空手而归；为命中项打上来源标签，并按「我的内容 → 资源篮 → 学科网」重排，让用户自己的、收藏的优先露出。

每次检索产出一个**冻结的结果集（round）**：每条 AI 回复携带它那一轮的 id，点击该回复下方的结果入口可精确重开那一轮结果，历史轮次永不被覆盖——「给你了就是你的」。这是找资源区别于普通搜索框的关键交互模型。

### 5.4 结果呈现

检索过程中右侧先展示「正在从学科网资源库检索匹配…」的骨架占位，确保结果不早于 AI 回复出现。检索完成后：

- AI 回复说明本轮理解（如「理解为七年级数学」）、检索总数、其中多少来自你的内容/资源篮收藏；
- 回复下方挂一个结果入口「已为你匹配 N 个资源」，点击查看本轮结果；
- 右侧结果舞台按轨道分页：全部 / 文档 / 视频 / 专辑；
- 每个资源卡片带来源标签（学科网 / 我的内容 / 资源篮）和关键字段（版本、学段学科、难度、题量/页数、是否已审校等）；
- 提供更多筛选：学段、学科、版本、类型、难度；
- 回复区提供本轮跟进建议（如视频轮：「只看实验视频」「教师研修视频」「下载这个视频」「据此配套出题」）。

资源回复是**内容感知**的：基于资源/视频的真实字段自洽生成，例如对视频说明其分章节、时长、画质、适合的课堂环节；对文档说明页数、题量、覆盖知识点、是否已审校。

### 5.5 资源操作

用户对单个资源可执行：

- 预览（文档）/ 播放（视频，支持按章节跳转）/ 展开专辑；
- 收藏入资源篮——收藏后该资源在后续轮次会带「资源篮」来源标签并优先排序；
- 下载；
- 追问该资源（「适合我们班吗」「用在哪个环节」「据此出题」），系统基于该资源真实字段回答。

### 5.6 跨场景流转

找资源的出口不止于「找到」。当已有资源不完全合适时，提供直接生成的流转入口（HANDOFF），把当前检索上下文（知识点、难度、学段学科）带到生成类场景：

| 流转动作 | 去向 | 说明 |
| --- | --- | --- |
| 直接出一份卷子 | 出卷子 | 从学科网题库按当前知识点和难度智能组卷 |
| 生成配套教案 | 写教案 | 对齐课标的教学设计 |
| 做成课件 | 做课件 | 结构清晰的 PPT |

这体现产品定位：不是脱离学科网另做一个通用搜索，而是把「检索已有资源」和「AI 生成新资源」组合成一条连续的备课链路——合适就收藏/下载，不合适就直接生成。

## 6. 异常与边界分支

| 分支 | 触发条件 | 系统处理 | 用户提示 |
| --- | --- | --- | --- |
| 未登录 | 用户未登录 | 「我的内容」来源不可用，记忆个性化降级为热门检索 | 提示登录后推荐更懂你、可保存资源篮 |
| 学科/学段过滤后为空 | 条件太严无命中 | 逐级放宽（先学段、再学科）兜底出一批 | 说明已放宽范围，可继续加筛选 |
| 完全无匹配 | 放宽后仍无结果（设想） | 不空手，回到示例引导或建议改写需求 | 提示换个说法或直接生成 |
| 资源形态识别错误 | 用户其实要视频却给了文档（设想） | 提供轨道切换和跟进建议快速纠偏 | 「只看视频」「有没有成套专辑」等一键跟进 |
| 模糊跟进无上下文 | 首轮就说「难度再高一点」 | 缺少累积上下文，触发一轮澄清（设想） | 询问学科/学段 |
| 下载/收藏需登录 | 未登录用户操作收藏/下载 | 拦截并引导登录 | 提示登录后可收藏到资源篮、下载 |
| 路由误判 | 把「三角函数是什么」误判为找资源 | 轻量确认或允许切换到问教材 | 允许手动切换场景 |

## 7. 关键原则回顾

- **结果冻结、可回看**：每轮检索是一个不可变的结果集，历史轮次永不覆盖，回复入口可精确重开——「给你了就是你的」。这是找资源的核心交互契约。
- **多源优先级**：我的内容 > 资源篮 > 学科网，让用户自己的和收藏的资源优先露出。
- **不空手而归**：过滤无命中时逐级放宽，宁可放宽范围也不返回空列表，配合明确的范围说明。
- **检索与生成连续**：找资源不是终点，资源不合适时一键流转到出卷子/写教案/做课件。
- **登录态分层**：登录解锁记忆个性化、我的内容、资源篮持久化；未登录走热门检索 + 引导登录。
- **内容感知回复**：AI 对资源的描述基于真实字段自洽生成，不空泛吹捧。
