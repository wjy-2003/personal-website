# 小博士记忆系统设计方案

> 版本：v0.1（2026-06-30）
> 状态：初稿，待评审
> 关联文档：[意图路由Agent设计方案](意图路由Agent设计方案.md)、[小博士场景意图路由策略](../docs/小博士场景意图路由策略.md)

---

## 1. 定位与设计原则

### 1.1 记忆系统的定位

记忆系统让小博士"认识"每位教师，核心价值是**降低重复输入**和**提升个性化体验**。

记忆的三个消费场景：

- **预填表单**：进入工作台时自动填入版本/学段/学科/年级，减少每次从头选择
- **个性化推荐**：找资源时优先推荐本地区、本版本、本年级的内容
- **意图消歧**：路由和场景 Agent 利用记忆理解模糊表达（"帮我出一套卷子"→ 人教版七年级数学中等难度）

### 1.2 设计原则

**透明可控**：每条记忆带形成依据，用户可查看、关闭、编辑。记忆不是黑箱。

**自动学习、不打扰**：从行为中推断偏好，达到置信度后自动生效，不逐条弹窗确认。用户通过记忆管理页事后管理。

**记忆不替用户做决定**：记忆提供默认值和快捷入口，不跳过用户确认步骤。例如问教材场景不自动打开上次的教材，而是提供"继续上次"卡片。

**结构化优先**：记忆以结构化数据为主体，自然语言摘要仅用于用户展示层。LLM 读取结构化数据，不读自然语言。

## 2. 数据架构

```
TeacherMemory
├── profile (永久层——教师身份特征，极少变化)
│   ├── stage              # 学段：小学/初中/高中
│   ├── subjects[]         # 任教学科，可多值（数学、信息技术）
│   ├── region             # 地区（省/市）
│   └── editions{}         # 学科→版本映射（数学→人教版，信息技术→北师大版）
│
├── preferences (永久层——从行为中学习的偏好)
│   ├── difficulty         # 偏好难度（易/中/难）
│   ├── with_answer        # 默认是否带答案
│   ├── with_analysis      # 默认是否带解析
│   ├── frequent_tasks[]   # 常做的任务类型（随堂练习、单元测试）
│   └── scene_prefs{}      # 场景级偏好
│       ├── paper          # 出卷子：{} 预留
│       ├── lesson         # 写教案：{ structure_style: "情境导入" }
│       ├── courseware     # 做课件：{} 预留
│       └── ...
│
├── semester (学期层——每学期可能更新)
│   ├── grades[]           # 当前教的年级，可多值（七年级、八年级）
│   ├── current_books{}    # 学科→当前册别（数学→七年级上册）
│   ├── teaching_focus[]   # 当前教学重点章节
│   └── active_textbook    # 问教材的"继续上次"（版本+学科+册+章节+时间）
│
├── entries[] (离散记忆条目——面向用户展示和管理)
│   ├── id                 # 唯一标识
│   ├── text               # 记忆描述（"常用人教版教材"）
│   ├── basis              # 形成依据（"近30天25次创作中23次选择人教版"）
│   ├── on                 # 开关，用户可关闭
│   ├── source             # implicit(行为推断) / explicit(用户告知)
│   ├── confidence         # 内部置信度（0-1），不展示给用户
│   ├── category           # 对应 profile / preferences / semester
│   ├── field              # 对应具体字段（editions.数学 / difficulty / ...）
│   ├── created            # 创建时间
│   └── updated            # 最近更新时间
│
└── summary                # 自然语言摘要，给用户看，200-300字
```

### 2.1 各层说明

**profile（永久层）**

教师的基本身份特征。学段、学科在教师职业生涯中基本不变；地区决定了教材版本池和资源本地化优先级；版本映射跟学科绑定，一般一学年不变。

地区的影响面：

- 教材版本：不同地区使用不同版本教材
- 资源推荐：找资源时优先推荐本地区的试卷、课件
- 考区关联：高三阶段，地区与高考考区、模拟考卷直接相关

**preferences（永久层）**

从行为中学习的偏好，跨学期保持。偏好难度、是否带答案/解析是出卷子场景的高频设置项，如果教师每次都选同样的值，记住可以减少操作。

场景级偏好（scene_prefs）存放各场景特有的偏好，比如写教案偏好"情境导入"结构。这些偏好粒度较细，只在对应场景内消费。

**semester（学期层）**

随教学周期变化的信息。年级、册别、教学重点会在学期切换时更新。active_textbook 记录问教材场景的上次阅读位置，支持"继续上次"。

### 2.2 不记忆的维度

以下维度是任务参数或筛选条件，不纳入记忆系统：

| 维度        | 理由                                    |
| --------- | ------------------------------------- |
| 课程（学段+学科） | 是 stage + subjects 的组合，不需要单独存储        |
| 学期编号      | 不需要记"第几学期"，grades + current_books 已覆盖 |
| 教学场景      | 产品的场景分类，不是教师特征                        |
| 年份        | 找资源时的即时筛选条件（"找2024年试卷"），每次不同          |
| 考试覆盖范围    | 校考/联考/统考是找资源和出卷子的筛选条件，会变，不适合固化为偏好     |
| 资源类型偏好    | 今天找视频明天找课件，每次需求不同，记下来反而干扰             |

### 2.3 行为统计 vs 记忆

行为统计（课件12份、卷子8份、收藏36个、下载120次）不在记忆模型中。它们从业务数据库直接聚合，仅在展示层（首页面板、记忆管理页）与记忆数据合并呈现。

区别：

- **记忆**：有推断、有结论、可开关（"常用人教版教材"）
- **统计**：纯事实计数、无推断、不可开关（"已生成12份课件"）

## 3. 记忆写入机制

### 3.1 两条写入路径

**路径一：隐式学习（主路径）**

```
用户行为 → 行为日志 → 聚合统计 → 达到阈值 → 生成记忆条目
```

每次用户在场景中做选择（选版本、选难度、选学段等），系统记录一笔行为日志。后台定期聚合（建议每次会话结束时触发），当某个选择的出现频率达到阈值，自动生成一条记忆条目。

**路径二：显式告知（快捷路径）**

用户在对话中主动说出身份信息——"我教初中数学"、"我们用的是北师大版"——直接写入记忆，不走置信度流程。

标记 `source: "explicit"`，basis 写"你在对话中告知（2026-06-30）"。

### 3.2 统计窗口定义

置信度计算统一使用**次数窗口**（最近 N 次同类操作），而非天数窗口。原因：教师使用频率差异大，高频用户每天多次、低频用户一周一次，按天数统计会导致低频用户样本不足。

| 用途 | 窗口 | 说明 |
|------|------|------|
| 置信度计算 | 最近 10 次同类操作 | "同类操作"指同一个选择维度，如"出卷子时选难度"、"做课件时选版本" |
| 衰减判断 | 最近 10 次同类操作 | 与置信度窗口一致 |
| summary 生成的行为输入 | 最近 30 天内的记录，取最近 10 条 | 30 天反映当前教学节奏，10 条控制 LLM 输入长度 |
| basis 文案中的时间表述 | 与实际计算窗口对齐 | 如"最近 10 次创作中 8 次选择人教版"或"近 30 天 25 次创作中 23 次选择人教版" |
| 过期清理 | 180 天（唯一使用天数窗口的场景） | 判断的是"多久没用"，与使用频率无关 |

### 3.3 置信度与阈值

隐式学习的核心逻辑：

| 阶段 | 条件 | 处理 |
|------|------|------|
| 观察期 | 同类操作累计次数 < 5 | 只记日志，不生成记忆 |
| 低置信 | 5 ≤ 次数 < 10，最近操作一致率 ≥ 60% | 生成记忆条目，confidence = 0.6，仅当前会话生效（session-level） |
| 高置信 | 次数 ≥ 10，最近 10 次一致率 ≥ 70% | 记忆条目升级为持久记忆，confidence = 0.8+，跨会话生效 |
| 衰减 | 最近 10 次中该选择占比下降到 < 50% | 降低 confidence；降到 0.3 以下自动标记为"待确认" |

**阈值说明**：以上数值为初始设定，需要根据上线后的实际数据调整。核心逻辑是"观察→低置信→高置信→衰减"的渐进过程。

**一致率的计算**：最近 10 次同类操作中，相同选择出现的比例。例如最近 10 次出卷子中 8 次选"中等"难度，一致率 = 80%。

### 3.4 basis 的生成

每条记忆的 basis（形成依据）需要让用户看懂为什么 AI 这么认为：

| source | basis 示例 |
|--------|-----------|
| implicit | "近 30 天 25 次创作中 23 次选择人教版" |
| implicit | "最近 5 份教案均包含情境导入环节" |
| implicit | "近 2 周教学内容集中在《有理数》《整式的加减》" |
| explicit | "你在 2026-06-30 的对话中告知" |

basis 在记忆条目更新时同步刷新（统计数字随新行为变化）。

### 3.5 冲突处理

当新行为与已有记忆冲突时：

- **显式告知覆盖隐式推断**：用户说"我换北师大版了"→ 直接更新 editions，不管之前的行为统计
- **隐式推断之间**：新频率超过旧频率 → 更新记忆；否则保持原记忆，新行为继续积累
- **用户手动编辑**：在记忆管理页修改的条目标记为 `source: "explicit"`，不再被隐式学习覆盖（除非用户再次手动改）

## 4. 记忆消费方式

### 4.1 各场景的记忆消费

| 场景 | 读取的记忆字段 | 消费方式 |
|------|--------------|---------|
| 找资源 | stage, subjects, grades, editions, region | 预填搜索上下文；推荐结果本地化优先；显示"已结合你的记忆"banner |
| 出卷子 | editions, grades, subjects, difficulty, with_answer, with_analysis | 预填出卷表单（版本/年级/学科/难度/答案/解析） |
| 做课件 | editions, grades, subjects | 预填课件设置表单 |
| 写教案 | editions, grades, subjects, scene_prefs.lesson | 预填教材信息 + 应用教案结构偏好 |
| 问教材 | active_textbook | "继续上次"卡片（不自动打开） |
| 画导图 | editions, grades, subjects | 预填学科/版本/年级 |
| 改作业 | editions, grades, subjects | 预填学科/年级 |
| 首页 | 全量 | 记忆面板展示（summary + tags + stats + 最近创作） |
| 意图路由 | stage, subjects, grades, editions, teaching_focus | 辅助消歧（模糊意图 + 记忆 → 精确场景） |

### 4.2 按需提取，不全量注入

每个场景只读取自己需要的字段，不把整个 TeacherMemory dump 进 prompt。这样做的好处：

- 省 token
- 减少无关信息对 LLM 的干扰
- 各场景的记忆消费逻辑独立，互不影响

### 4.3 LLM 注入格式

场景 Agent 的 system prompt 中，记忆以结构化文本注入：

```
[教师画像]
学段: 初中
学科: 数学
年级: 七年级
地区: 河北·保定
版本: 人教版
偏好难度: 中等
带答案: 是
带解析: 是
当前重点: 有理数、整式的加减
```

路由 Agent 注入更精简的版本：

```
[教师画像] 初中/数学/七年级/人教版/河北保定
[当前重点] 有理数、整式的加减
```

### 4.4 记忆预填的 UI 表达

各场景在使用记忆预填时，统一使用 MemoryNote 组件提示用户：

- 登录态："已套用你的记忆：人教版 · 七年级 · 数学，下面可直接改。"+ 「清空」按钮
- 未登录态：不预填，显示登录引导

用户点"清空"后，本次会话内不再自动预填（避免反复套用用户已拒绝的默认值）。

## 5. summary 生成策略

### 5.1 定位

summary 是"小博士眼中的你"——一段自然语言描述，让用户感受到"小博士真的了解我"。它只承担展示职责，不参与 LLM 推理。

### 5.2 生成方式

**输入**：当前全量 entries（on=true 的）+ profile + semester + 最近 30 天内的创作/使用记录（取最近 10 条）

**输出**：200-300 字的自然语言段落

**生成时机**：

- 新记忆条目写入或更新时
- 用户手动修改记忆时
- 不需要实时——异步生成，下次打开首页时展示新版本

**Prompt 示例**：

```
你是学科网 AI 小博士。根据以下教师画像数据，生成一段 200-300 字的自然语言描述。
要求：第二人称（"你"），语气温暖但不油腻，重点突出近期教学重心和使用习惯，
不要罗列数据，要像一个了解你的助手在自然地描述观察到的情况。

[教师画像数据]
{结构化数据 JSON}

[近期行为]
{最近5条创作/使用记录}
```

### 5.3 展示层

- **首页记忆面板**：完整展示 summary 全文
- **记忆管理页**："小博士对你的总结"区域展示 summary
- **收起态**：面板收起后显示"记忆面板已收起——小博士仍在为你记忆"

## 6. 学期切换机制

### 6.1 核心策略：行为变化检测 + 时段兜底提醒

不依赖固定日期判断学期切换，而是通过检测用户行为变化来触发。

### 6.2 行为变化检测

**触发条件**：系统检测到用户连续 3 次以上选择了与当前记忆不同的年级或册别。

例如：记忆中 grades = ["七年级"]，current_books.数学 = "七年级上册"，但用户最近 3 次出卷子/做课件都选了"七年级下册"或"八年级上册"。

**触发动作**：在下次会话开始时，小博士主动提问：

> "我注意到你最近在准备八年级的内容，要更新你的教学信息吗？"
>
> [更新为八年级]  [暂时不用，只是提前准备]

用户选择"更新"→ 批量更新 semester 层（grades、current_books、teaching_focus 清空重建）。

用户选择"暂时不用"→ 本轮不再提醒，但如果行为持续偏离，下一轮会话再次提醒。

### 6.3 时段兜底提醒

每年两个时段（8 月 20 日 - 9 月 10 日、2 月 10 日 - 3 月 1 日），如果用户在此期间活跃，首页显示轻量提示卡片：

> "新学期即将开始，检查一下你的教学信息是否需要更新？"
>
> [去检查]  [不需要]

这是被动提示，不强制。点"去检查"跳转到记忆管理页。

### 6.4 学期切换时的数据处理

| 数据层 | 处理方式 |
|--------|---------|
| profile | 不变（学段、学科、地区、版本通常不变） |
| preferences | 不变（偏好跨学期保持） |
| semester.grades | 更新为新年级 |
| semester.current_books | 更新为新册别 |
| semester.teaching_focus | 清空，等待新行为重新积累 |
| semester.active_textbook | 清空（新学期通常换教材） |
| entries | 与 semester 相关的条目标记为"待更新"，等新行为覆盖 |
| summary | 学期切换后触发重新生成 |

## 7. 记忆管理

### 7.1 用户侧管理

**记忆管理页**（左侧导航"我的记忆"）：

- **"小博士对你的总结"**：展示 summary 全文
- **教学画像标签**：学科/学段/年级/版本等，可点击编辑
- **记忆条目列表**：每条显示 text + basis + 开关
	- 关闭某条 → 该记忆不再参与预填和推荐，但保留数据（用户可重新打开）
	- 删除某条 → 数据移除，如果后续行为再次触发同样的模式，会重新生成
- **手动添加**：用户可主动添加记忆（"我还教高二物理"），标记为 source: "explicit"

### 7.2 系统侧管理

**过期清理**：

- 超过 180 天未被任何行为强化的隐式记忆，confidence 自动衰减
- confidence 降到 0.1 以下 → 自动关闭（on = false），不删除
- 用户显式添加的记忆不参与自动衰减

**合并去重**：

- 如果两条记忆指向同一个字段（比如都是关于版本偏好），保留 confidence 更高的，合并 basis

## 8. 登录态与未登录态

### 8.1 登录态

- 记忆系统完整可用
- 首页展示记忆面板（summary + tags + stats + 最近创作）
- 各场景工作台预填记忆
- 行为持续写入，记忆持续学习

### 8.2 未登录态

- 记忆系统不可用
- 首页记忆面板替换为"登录解锁小博士记忆"引导：
	- 列出三个可解锁能力（记住偏好/个性化推荐/续作）
	- 标注"未登录也可正常使用全部场景"
- 各场景工作台不预填，用户每次手动选择
- 行为不记录（无法关联到用户身份）

### 8.3 新用户冷启动

首次登录的用户没有任何记忆。冷启动策略：

- **首次使用引导**：不主动弹出问卷，而是在用户首次进入需要教学信息的场景时（如出卷子），正常展示表单让用户填写。填写的信息同时作为 source: "explicit" 写入记忆
- **快速积累**：前 5 次使用期间，降低隐式学习的阈值（3 次一致即生成低置信记忆），加速冷启动
- **首页提示**：记忆面板显示"小博士正在了解你，使用几次后就能记住你的偏好"
