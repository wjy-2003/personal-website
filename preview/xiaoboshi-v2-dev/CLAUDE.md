# AI 小博士 · 智能教学助手

## 一期 PRD 要点（uploads/新版小博士一期PRD.md）

### 对话式场景（4个，首页chip + 工作台pills）
- **找资源** (find) — 双栏检索，筛选条+资源卡片，检索轮次冻结回看
- **做课件** (courseware) — 初始态→大纲态→内容态→跳模板选择页(旧版)
- **写教案** (lesson) — 同做课件流程，收尾改为「编辑」+「下载」
- **画导图** (mindmap) — 直接生成，节点可编辑/折叠/标重点/加子节点

### 通用助手 (general)
- 首页自由输入的落点和意图识别兜底，**不单独占chip**
- 右侧场景区显示4张场景卡片
- 识别中时右侧显示动效+"正在理解你的需求…"

### 旧版保留入口（左侧菜单，点击跳转旧版页面）
互动课件、智能组卷、教材百科、作文批改、AI 讲卷、AI 生图、智能体

### 做课件/写教案共用流程（PRD §3/§4/§10）
1. **初始态**: 引导语 + 教材选择器入口 + 示例
2. **参数**: 学段+学科+教材版本+章节，全必填，缺则弹补全卡（对话流内卡片）
3. **大纲态**: 卡片头(章节名) + 一级模块列表(拖拽/改名/删除/折叠) + 添加模块区(候选) + 主按钮
4. **内容态**: 逐节流式生成 + 浮动目录(✔done/◐generating/○pending) + 自动保存
5. **收尾**: 做课件→「生成课件」跳模板页；写教案→「编辑」+「下载」

### 关键文案
- 做课件初始: "来做课件吧" / AI首句: "好的，我来帮你做课件。告诉我课题，或者在右侧选好教材章节，我先给你列个大纲。"
- 写教案初始: "来写教案吧" / AI首句: "好的，我来帮你写教案。告诉我课题，或者在右侧选好教材章节，我先给你列个大纲。"
- 通用助手: "你好，我是 AI 小博士。教学上的问题都可以问我；当你需要找资料、做课件、写教案时，我会在右侧为你打开对应的场景。"
