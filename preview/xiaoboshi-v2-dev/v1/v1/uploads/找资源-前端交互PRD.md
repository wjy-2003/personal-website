## 1. 目标

找资源前端需要让教师完成三件事：

1. 一句话说清需求：不用先选筛选项也能直接找；
2. 信息不够时被高效补齐：只问缺的，不问所有维度；
3. 找到即用：预览、收藏、下载、追问、或不合适时直接生成，都在同一个对话里完成。

设计原则：

- 结果冻结、可回看——每轮检索是不可变结果集，历史轮次永不覆盖；
- ~~不空手而归——过滤无命中时逐级放宽，宁可放宽范围也不返回空列表；~~
- 追问只问缺口——按资料类型算最小必要字段，缺什么问什么，不做通用大表单；
- 检索与生成连续——资源不合适时一键流转到生成类场景；
- 移动端也能完整使用。

## 2. 页面结构

找资源工作台采用左右双栏形态：

```text
左侧：对话面板（ChatPanel）—— 输入 + 对话历史 + 追问弹框 + 跟进建议
右侧：结果舞台（Stage）—— 场景切换栏 + 冷启动/检索中/结果列表/资源详情
```

桌面端：

- 左右两栏可拖拽调整宽度（左侧最小 320px，右侧内容区最小 380px），拖拽位置持久化；
- 右侧舞台可收起（对话栏占满宽度）或进入全屏（覆盖整个视口，聚焦查看结果）；
- 左侧收起时顶部出现「展开菜单」「新对话」两个图标按钮。

移动端：

- 对话为主屏，结果通过底部抽屉（`MobileSheet`）呈现；
- 新一轮结果产生、或用户点击查看某轮结果时，抽屉自动上滑展开；
- 顶部标题栏用「资源」标签 + 图标标识当前抽屉内容。

## 3. 入口

| 入口 | 行为 |
| --- | --- |
| 首页「找资源」场景 pill | 直接进入找资源冷启动页 |
| 通用输入框路由命中 | 带入用户问题，经过场景识别动画后开始首轮检索 |

入口文案固定为：**找资源**。

## 4. 冷启动页

无输入进入找资源时，左侧对话面板显示一条固定问候：

```text
老师你好，告诉我你要找什么 —— 教案、课件、试卷都行，
例如「人教版七年级数学有理数课件」。
我会从学科网资源库为你精准匹配。
```

问候语的例子按**资源类型**（教案/课件/试卷…）表达，贴近老师的自然表达习惯。例子固定为通用示例，不做记忆个性化——记忆个性化的展示职责由右侧 `FindColdStart` 面板承担（见下表）。

同时右侧结果舞台展示 `FindColdStart` 冷启动面板，内容随登录态分化：

| 区块 | 已登录（有记忆画像） | 未登录 |
| --- | --- | --- |
| 顶部提示条 | 品牌浅色背景："已结合你的记忆 **人教版 · 七年级 · 数学** 为你推荐，下面都是按你的偏好挑的。" | 虚线边框："登录后，小博士会记住你的学段学科，把推荐变得更懂你。" + 就近的「登录」按钮 |
| 热搜标签 | 标题"为你推荐"：按画像挑选的 5 条，可穿插 1-2 条视频/专辑类查询 | 标题"热门检索"：通用热搜 5 条，可穿插 1-2 条视频/专辑类查询 |
| 示例分类卡（3 张，横排） | 按教学场景分组（见下），示例内容结合记忆个性化 | 按教学场景分组（见下），示例内容为通用示例 |

未登录顶部提示条的登录按钮点击后弹出全局登录弹窗（`LoginModal`），行为与站内其他登录触发点一致：登录成功后不跳转页面，冷启动面板根据 `loggedIn` 状态自动切换为已登录展示。

### 4.1 示例分类卡分组

示例分类卡按**教学场景**分组，对齐标签树 [32] 应用场景体系（`数据/原始数据/标签树/应用场景标签树.md`）：

| 分类卡 | 对应场景 | 找什么 |
| --- | --- | --- |
| 同步教学 | 同步练习/周测/单元测试/知识点 | 按教材章节找课件、教案、同步练习 |
| 同步备考 | 开学考试/月考/期中/期末 | 找试卷 |
| 复习冲刺 | 一轮复习/二轮专题/三轮冲刺/模拟/真题 | 找复习资料、真题 |

视频、专辑类需求体量小（2026年5月数据：视频类需求占比 3.8%，专辑/合集更多是内容运营侧的推荐诉求而非老师主动搜索），穿插在热搜标签里保留入口，不单独占分类卡位置。

**"复习冲刺"卡片的个性化规则**：记忆中的年级为毕业年级（九年级/高三）时，展示"一轮复习""二轮专题""真题"等示例；记忆年级为非毕业年级（七/八年级、高一/高二）时，展示更通用的"专题复习/易错题"示例。未登录时统一展示通用示例。

所有热搜标签和示例条目均可点击直接发起一轮检索（等效于用户输入该文本）。

## 5. 输入区

对话面板底部固定输入区（复用首页 SmartInput 的视觉规范，紧凑版），从上到下：

- 附件 chip 区：有已上传附件时展示，位于输入框内部、文本框上方，可点击预览、可移除；
- 多行文本框：超过约 5 行内滚动；
- 底部工具行：附件按钮（左）+ 发送按钮（右）；
- 输入区下方固定文案："AI 内容仅供教研参考"。

附件按钮支持图片/文档上传，上传态经历"上传中 → 解析中 → 就绪"三阶段，解析未完成时发送按钮禁用。

### 5.1 跟进建议与 placeholder：同一套推断逻辑

跟进建议（输入框上方，最多 3 条）和 placeholder 共用同一套判断依据：**当前这批结果最值得追问的维度**。跟进建议只延伸"找"这个动作本身，不承担生成类的引导——生成入口由结果列表底部的跨场景流转条、以及资源详情页"问小博士"里的对应问题承担。

"找"的延伸只有四类：

| 延伸方向 | 说明 | 示例 |
| --- | --- | --- |
| 精炼当前结果 | 缩小同一批资源的筛选条件 | 换个难度 / 只要含答案解析的 / 换个版本 / 换个年级册次 |
| 换资源类型 | 主题不变，换一种资源形式 | 换成看看课件 / 有没有配套学案 / 有没有讲解视频 |
| 换主题或章节 | 同学科内延展 | 换个章节 / 类似知识点还有吗 |
| 要更多同类结果 | 同一批条件下看更多 | 再多看几个 / 换一批 |

具体展示哪 3 条，按当前结果最缺的维度动态选取：

- 结果已明确版本+年级但未分难度：优先"换个难度"、"只要含答案解析的"；
- 结果以试卷/真题为主：优先"只看近三年的"、"换个地区的"、"只要含答案解析的"（时新度和地区对试卷类最敏感，对课件/教案类不适用）；
- 结果以视频为主：难度、答案解析等维度不适用，优先"再多看几个"、"换个知识点的视频"；
- 结果以专辑为主：专辑是打包好的整体，精炼筛选意义不大，优先"展开来看"、"换一套"。

placeholder 取跟进建议池的第一条，与 chip 用词保持一致；没有任何结果时（冷启动阶段），退回抽象通用文案："告诉我你要找什么，或换个方向再试试"。追问弹框打开时，placeholder 固定为"选上方，或直接在这里描述你要找的资源…"。

## 6. 对话流程与文案

以下按典型路径给出完整的轮次walkthrough，每一步标注实际展示文案，供前端还原时对照。

### 6.1 路径一：信息充分 → 直接检索

1. 用户输入：「人教版七年级上《有理数》同步练习，中等偏上」
2. 系统识别：学科=数学、学段=初中、年级=七年级、类型=作业/试卷、主题=有理数，信息已充分，不触发追问
3. 右侧舞台切换为骨架占位（`RetrievingPanel`），顶部文案：

   ```text
   ⋯ 正在从 学科网资源库 检索匹配…
   ```

   下方 5 行骨架卡片依次浮现（错峰动画）

4. 检索完成，AI 回复插入对话（`roundReplyNode`）：

   ```text
   已按你的需求（理解为 七年级数学），从学科网资源库检索整理出 12 项，
   其中 2 项来自你的内容、1 项来自资源篮收藏。
   点下方查看，合适就收藏或下载，不合适我也能直接生成。
   ```

5. 回复下方出现结果入口（`ResultPill`）：「已为你匹配 12 个资源」+ 「点此查看本轮结果」
6. 右侧舞台展示结果列表，头部：「以下是为你匹配的资源」+ 数量徽标 + 来源标签（我的内容/资源篮/学科网）
7. 输入框上方出现跟进建议 chip：本轮结果以试卷/作业为主，按 §5.1 的选取逻辑展示"换个难度"、"只要含答案解析的"、"换个章节"

### 6.2 路径二：信息不足 → 追问补全

1. 用户输入：「找点试卷」（仅资源形态明确，学科/学段缺失）
2. 系统识别到类型=试卷（测练类），但学段、学科缺失，触发追问，先插入一条铺垫文案（`clarifyIntro`，随缺口程度变化）：

   - 仅缺资料类型时：
     ```text
     已经识别到你要找的是《{主题}》（{已识别上下文}）——
     只差一步：你想要哪一类资料？课件、教案还是试卷？下面选一下就好。
     ```
   - 有部分上下文或已识别类型时：
     ```text
     好的，帮你找{类型}（已识别 {已识别上下文}）——
     再补一下 {缺失字段}，我就能精准检索。
     ```
   - 完全无上下文时：
     ```text
     好的，帮你找{用户提到的资源词}——
     先确认 {缺失字段}，免得给你一堆不相关的。下面选一下，也可以直接打字告诉我。
     ```

3. 对话面板底部弹出补全卡（`ClarifyPopover`，详见 §7），标题："只差一步 —— 补齐后我就能为你精准检索"或"帮你补齐**最小必要信息**，筛得更准"
4. 用户在补全卡中选择学段→学科→场景（试卷属于测练类，只需场景字段，如"期中"）
5. 提交后，对话中插入一张「已答」摘要卡：

   ```text
   补齐资源信息：初中 · 数学 · 期中
   ```

6. 进入路径一的第 3 步（骨架占位 → 结果呈现）

### 6.3 路径三：模糊跟进（依赖累积上下文）

1. 前序轮次已确认学科=数学、学段=七年级
2. 用户追加输入：「难度再高一点」
3. 系统判定为模糊跟进（不含新的明确资料类型/学科等信息），不触发追问，直接吸收累积上下文 + 新条件，进入检索（路径一第 3 步起）
4. AI 回复文案同样按 `roundReplyNode` 模板生成，理解上下文显示为「七年级数学」

### 6.4 路径四：资源详情追问（问小博士）

1. 用户点击某个资源卡片，进入详情视图（文档 `PreviewDrawer` / 视频 `VideoPlayer` / 专辑 `AlbumPage`）
2. 详情视图底部固定「问小博士」追问条（`AskBar`），按资源类别动态生成 2-4 条问题：
   - 固定问题（内容 RAG 类）：如"总结这份资料的考点"（试卷/作业）、"总结这份课件的教学重点"（课件）
   - 固定问题（画像对比类，仅登录可见）："这份适合我的班级吗？"
   - 动态问题（生成 handoff 类）：如"据此出一份同类卷子"（试卷/作业 → 出卷子）、"据此生成一份教案"（课件 → 写教案）
3. 用户点击某个问题：
   - **内容 RAG / 画像对比类**：该问题连同资源引用卡一起以用户消息形式插入对话，AI 基于资源真实字段生成回答（`replyForResource`），详情视图保持打开，对话区自动滚出可见
   - **生成 handoff 类**：不追加对话消息，直接携带资源引用（`ChatSession.handoffRef`）切换到目标场景（出卷子/写教案），种子消息为"据《{资源标题}》{出一份同类卷子/生成配套教案}"
4. 用户从生成场景通过引用卡返回时，找资源自动重新打开该资源详情

### 6.5 路径五：无结果兜底与跨场景流转

1. 检索结果为空（`items.length === 0`）
2. 右侧舞台展示 `NotFound` 空态：

   ```text
   当前条件下暂无现成资源完全匹配
   先把需求说得更具体些（学段、版本、知识点、难度…），我再帮你精准筛一批；
   或者 —— 让小博士基于学科网资源库直接为你生成
   ```

3. 下方展示跨场景流转条（`HandoffBar`，见 §10），提供出卷子/写教案/做课件三个入口

有结果但不完全合适时，`HandoffBar` 同样出现在结果列表底部（不是仅在空态才出现），标题："没找到完全合适的？把需求说得更具体些我再帮你精准筛选 —— 或让小博士基于学科网资源库直接生成"

## 7. 追问/澄清弹框（ClarifyPopover）

补全卡是找资源区别于简单搜索框的关键交互，规格如下：

**触发条件**：仅对文档类找资源意图生效（视频/专辑形态另走分轨，不触发）；当前输入或累积上下文经解析后，按资料类型对应的最小必要字段清单存在缺口。

**最小必要字段（按类型）**：

| 资料类型 | 除学段/学科/类型外还需要 |
| --- | --- |
| 备课类（课件/教案/学案） | 年级 + 主题 |
| 测练类（试卷/作业） | 场景（期中/期末/一模/真题等） |
| 类型未定 | 先补齐"资料类型"本身 |

**卡片结构：**

- 顶部：图标 + 标题（"只差一步" 或 "帮你补齐最小必要信息"）+ 关闭按钮
- 已识别字段区（仅当有已识别字段时展示）：折叠为一行小标签"已为你识别"，每个标签可点击"改"重新展开为可选状态
- 待选字段区：按依赖顺序展开（学段 → 学科 → 类型 → 类型专属字段），每个字段：
	- 标签行标注该字段是"必选"还是"（可不限）"
	- 选项以 chip 形式横排，点击即选中
	- "主题"字段为文本输入框，可搭配"暂不指定"按钮
- 底部：左侧"跳过，先给我看大致结果"文字按钮；右侧提交按钮，未补齐必选项时禁用并显示"请补齐必选项"，补齐后显示"检索 {已选摘要}"

**交互细节：**

- 学段与学科存在依赖关系：未选学段时学科选项区提示"请先选择学段"；切换学段后，已选的学科/年级若不在新学段范围内会被清空
- 支持键盘操作：Enter 在必选项补齐后等效于点击提交，Esc 等效于跳过
- 跳过后，同一会话内后续仅靠上下文的模糊输入不再重复弹出补全卡；但如果用户带了新的明确信息（如新提到的资料类型），会重新激活判断

## 8. 结果呈现区

### 8.1 检索中状态

骨架占位（`RetrievingPanel`）：顶部固定文案"正在从 学科网资源库 检索匹配…"（配加载点动画），下方 5 行卡片骨架错峰浮现（`animationDelay` 依次递增）。骨架状态期间右侧不展示任何真实结果，确保结果不早于 AI 回复文本出现。

### 8.2 结果列表头部

- "以下是为你匹配的资源" + 数量徽标（品牌浅色 pill）
- 来源标签横排（仅展示实际存在的来源）：我的内容 / 资源篮 / 学科网，每个标签为彩色圆点 + 文字

### 8.3 资源卡片（三种形态）

| 卡片类型 | 组件 | 关键字段 |
| --- | --- | --- |
| 文档 | `ResourceCard` | 匹配度环形进度条（百分比数字居中）、标题（2 行截断）、类型 badge、版本+学段学科、附加 chips（最多 4 个）、题量/页数、来源标签 |
| 视频 | `VideoCard` | 横版缩略图（时长角标 + 分类角标）、标题、学段学科、画质、章节数、播放量、来源标签 |
| 专辑 | `AlbumCard` | 堆叠封面（总份数数字）、专辑徽标、版本学段学科、标题、构成说明（如"含 课件3 · 教案2 · 试卷5"） |

## 9. 资源详情与操作

### 9.1 文档预览（PreviewDrawer）

- 头部：返回按钮 + 标题 + 页数/题量/更新时间 + 关闭按钮
- 主体：分页预览（模拟文档排版）
- 底部固定：「问小博士」追问条（§6.4）+ 「加入资源篮」「下载文档」按钮

### 9.2 视频播放（VideoPlayer）

- 头部：返回 + 标题 + 时长/画质 + 关闭
- 主体（桌面端左右分栏，移动端上下）：
	- 左/上：播放器舞台（暗色背景，播放/暂停控制、进度条可拖拽跳转、当前章节名浮层、倍速/画质/全屏控制）
	- 右/下：章节列表，点击跳转到对应时间点，当前播放章节高亮
- 底部固定：「问小博士」追问条 + 「加入资源篮」「下载视频」按钮

### 9.3 专辑详情（AlbumPage）

- 头部：返回搜索结果
- 封面区：堆叠封面（总份数）+ 专辑标题 + 版本学段学科 + 下载次数/更新时间 + 「加入资源篮」「一键打包下载整个专辑」
- 构成条：横向色块条按资料类型分段（课件/教案/试卷…比例可视化）+ 图例
- 全量层级列表：单元 → 课时 → 资料（文件类型徽标 + 标题 + 类型/页数/题量），点击单条资料打开该条的文档预览
- 底部固定：「问小博士」追问条（合集级问题，如"这个合集涵盖哪些知识主题"）

### 9.4 操作反馈

- 收藏（加入资源篮）：成功提示 toast "已加入资源篮"，已在资源篮中提示 "已在资源篮中"
- 下载：toast 提示 "已开始下载《{标题}…》"（专辑为 "已开始打包下载整个专辑"）
- toast 展示 2.2 秒后自动消失，位置固定在结果区底部居中

## 10. 跨场景流转（HandoffBar）

出现位置：结果列表底部（资源不完全合适时的常驻提示）、无结果空态（`NotFound`）。

- 提示文案："没找到完全合适的？把需求说得更具体些我再帮你精准筛选 —— 或让小博士基于学科网资源库直接生成"
- 三个流转入口横排，点击后携带当前轮次的检索上下文（学科/学段/主题）切换场景，种子消息为"基于「{主题}」"或用户原始 query

| 动作 | 去向场景 | 说明文案 |
| --- | --- | --- |
| 直接出一份卷子 | 出卷子 | 从学科网题库按当前知识点和难度智能组卷 |
| 生成配套教案 | 写教案 | 对齐课标的教学设计 |
| 做成课件 | 做课件 | 结构清晰的 PPT |

## 11. 会话内成果与任务续接

找资源与其他场景共享以下跨场景状态机制：

- **本次对话的成果菜单**（`SessionArtifactsMenu`，对话头部右上角）：汇总本次会话中所有场景产出的"冻结成果"（含找资源的检索轮次、出卷子/写教案的产出），点击任意条目重新打开对应轮次/成品，无成果时不显示入口
- **草稿续接条**（`SessionTaskBar`，输入框上方）：当教师在其他场景（出卷子/写教案）有未完成的草稿，且当前不在该场景时，显示一条可点击的续接提示（虚线=草稿中，实线品牌色=已生成），点击直接跳转继续
- **跨场景引用卡**：从资源详情"问小博士"发起的生成 handoff，在目标场景的种子用户消息上方会带一张资源引用卡，点击可跳回找资源重新打开该资源

## 12. 移动端适配

- 对话优先，占满主屏；
- 结果通过底部抽屉呈现，新一轮结果产生或点击查看结果时自动上滑展开；
- 顶部标题栏：菜单按钮 + 助手身份 + 新对话按钮；抽屉内独立标题栏显示"资源"标签；
- 追问补全卡、资源详情（预览/播放/专辑）均以全屏或近全屏形式呈现；
- 视频播放器章节列表移至播放器下方（高度不超过视口 42%）；
- 输入区固定底部，附件 chip 不遮挡输入。

## 13. 异常状态

| 异常 | 前端表现 |
| --- | --- |
| 未登录 | 冷启动展示登录引导条，"我的内容"来源不参与排序，收藏/下载被拦截并弹出登录提示 |
| 上传附件失败 | chip 显示失败态，可重试/删除 |
| 学科/学段过滤后为空 | 逐级放宽（先学段再学科），结果头部说明已放宽范围 |
| 完全无匹配 | 展示 `NotFound` 空态 + `HandoffBar` 跨场景生成入口 |
| 追问被跳过 | 用累积上下文直接给一批结果，不空手而归 |
| 路由误判（如把"三角函数是什么"误判为找资源） | 允许手动切换到问教材场景 |
| 检索中网络异常（待补充） | 需定义超时重试与错误提示文案 |
