# 资源详情页 — 问题列表交互设计

**创建日期：** 2026-06-14  
**状态：** 设计草案（待产品确认）  
**定位：** 描述找资源场景下，用户进入资源详情页后"问小博士"入口的交互逻辑、问题配置策略和后端处理方案。供产品与开发对接使用。  
**关联文档：** 《找资源场景-实现步骤与系统提示词》；产品设计文档 §UI-5、§2.4  

---

## 1. 核心交互原则

**遵循「一条会话贯穿」产品原则：**

用户在找资源场景下点击资源详情页的问题，消息发送到**左侧对话面板（现有对话）**，不开新会话、不切换场景。找资源的历史对话线索不中断。

右侧面板保持显示资源详情，场景标识仍是"找资源"。

后端的处理路径不同（见 §4），但对用户透明，感知为"同一位助手回答了资源相关问题"。

---

## 2. 问题列表的生成逻辑

问题列表**纯前端生成**，不调用 LLM，不需要网络请求。

根据资源的**资源类别（类型字段）**，从预设模板中取对应题组，2 个固定 + 1~2 个动态，总数不超过 5 个。

### 2.1 固定问题（全部资源类别共用）

| 问题文本 | 备注 |
| --- | --- |
| 总结这份资料的考点 / 教学重点 | 文字根据资源类别微调（试题→考点；课件/教案→教学重点） |
| 这份适合我的班级吗？ | 依赖记忆系统；记忆系统未完成前**隐藏此入口** |

### 2.2 动态问题（按资源类别配置）

| 资源类别 | 动态问题 |
| --- | --- |
| 试题试卷 | 「这道题怎么讲」「据此出一份同类卷子」 |
| 课件 | 「提取这份课件的教学目标」「据此生成一份教案」 |
| 教案/讲义 | 「整理一下这份教案的教学流程」 |
| 学案/导学案 | 「提取学生学习目标和重点」 |
| 音视频 | 「总结视频要点」（依赖字幕/转写文本；无转写文本时**隐藏此入口**） |
| 素材 | 无动态问题（图片为主，无法做内容 RAG） |
| 备课综合 | 「提取教学设计思路」 |
| 假期作业 | 「据此出一份同类练习」 |
| 专辑 | 「这个合集涵盖哪些知识主题」（针对集合整体；子资源列表通过独立接口获取） |

### 2.3 展示规则

```
题组上限 = 2（固定） + 2（动态） = 最多 4 个
若某条件不满足（记忆系统未就绪 / 无字幕）→ 对应问题入口隐藏，不占位
专辑详情页：只展示专辑级问题，不展示子资源各自的问题入口
  └ 固定问题文字调整为"总结这个合集的主题范围"
专辑子资源点击后进入该子资源的资料详情页，按普通资料类型展示对应问题，与专辑无关
```

## 3. 点击后的前端处理

用户点击问题后：

1. 前端**将资源上下文打包**进消息体：

```text
[资源上下文]
资源ID：{resource_id}
标题：{title}
类别：{type}  学科：{subject}  学段：{grade}  难度：{difficulty}
版本：{edition}
{如有：内容摘要 / 前N段正文 / 视频字幕片段}

[用户问题]
{问题文本}
```

2. 消息在左侧对话中显示时，**气泡上方以独立引用块形式显示资源引用卡片**（资源标题 + 类别），让用户清楚这条问题针对哪份资源。

   引用卡片点击行为：
   - **该资源当前已在右侧打开** → 提示"已打开"，不切换
   - **该资源当前未在右侧打开** → 右侧面板打开该资源详情

   特殊情况：如果问题触发了 C 类 handoff（如"据此出一份卷子"），右侧面板已切换到出卷子场景。此时点击引用卡片，右侧面板切回该资源详情（出卷子草稿保留，可通过对话下方入口重新进入，见 §4 C 类）。

3. 后端根据消息体里的 `resource_id` 和问题类型，**走不同的处理路径**（见 §4），不触发 `search_resources`。

> ⚠️ 关键点：消息打包了资源上下文，后端需要能识别"这是资源详情发来的消息"与"用户手打的普通消息"的区别，避免意外触发资源搜索流程。产品层设计为在**消息体中加来源标记字段**，如 `source: "resource_detail"`；具体实现方式（消息体字段还是 header）由开发决定。

## 4. 后端处理方式（三类）

### A. 内容 RAG 类

**适用问题：** 总结考点/教学重点、讲题、提取教学目标/学习重点、总结视频要点、整理教学流程

**依赖：** 资源正文文本（文档类需 PDF/Word 解析；视频需字幕或转写文本）

**处理流程：**

```
收到消息
→ 按 resource_id 查缓存，命中则直接用
→ 未命中：实时拉取并解析正文文本，解析完成后写入缓存（相同资源下次直接用）
→ 截取相关段落（RAG 或全文，视长度）
→ 注入 LLM prompt，要求基于提供文本回答
→ 不检索新资源
```

> **正文解析策略说明**：采用"首次实时解析 + 结果缓存"方案。同一份资源第一个访问的用户会经历完整解析耗时，后续用户直接命中缓存。实际性能需上线后测试；如首次耗时过长，再考虑离线预处理。

**降级策略：** 如果正文文本不可用（解析失败 / 未处理），基于标题 + 元数据作答，并在回复中注明"仅基于资源描述，未读取正文"。

### B. 画像对比类

**适用问题：** 这份适合我的班级吗？

**依赖：** 用户记忆系统中的 `tags`（学科/学段/偏好难度），以及资源元数据

**处理流程：**

```
收到消息
→ 读取用户记忆系统 tags
→ 与资源的学科/学段/难度字段做对比
→ LLM 输出判断 + 理由
→ 不检索新资源，不需要正文文本
```

**降级策略（分两种情况）：**

- **情况一：记忆系统尚未建设**（功能未上线）→ 前端**隐藏此入口**，不展示。
- **情况二：记忆系统已建设，但当前用户无数据**（tags 为空）→ 展示入口，点击后在**左侧对话**中提示用户完善信息，例如：

  > 「要判断这份资料是否适合你的班级，需要了解你的基本情况。请告诉我：
  > 1. 你教的学科和学段（如：初中数学）
  > 2. 班级难度偏好（基础 / 中等 / 拔高）
  >
  > 你可以直接选择或补充说明。」

  用户回复后，记忆系统写入 tags，后续同类问题可直接对比作答。

### C. 生成 handoff 类

**适用问题：** 据此出一份同类卷子、据此生成教案

**依赖：** 资源元数据（知识主题、学科、学段、难度）

**处理流程：**

```
收到消息
→ 识别为生成 handoff
→ 提取资源的知识主题 + 学科 + 学段 + 难度
→ 右侧面板切换到对应生成场景（出卷子 / 写教案），携带上述参数
→ 左侧对话线索不中断
```

> handoff 只改右侧面板，左侧对话继续。与找资源场景内的跨场景 handoff 机制相同。

**草稿保留：** C 类 handoff 产生的出卷子/教案草稿处于**未完成态**，用户从资源详情切回后草稿不丢失。草稿入口显示在**左侧对话消息下方**，样式与找资源的 round 回看入口一致，用户点击可重新进入该草稿继续编辑。

## 5. 按资源类别的完整对应表

| 资源类别 | 可用处理方式 | 问题入口总数 |
| --- | --- | --- |
| 试题试卷 | A（考点/讲题）+ B（适配）+ C（出同类卷） | 最多 4 |
| 课件 | A（教学目标/重点）+ B（适配）+ C（生成教案） | 最多 4 |
| 教案/讲义 | A（教学流程/思路）+ B（适配） | 最多 3 |
| 学案/导学案 | A（学习目标/重点）+ B（适配） | 最多 3 |
| 音视频 | A（视频要点，依赖字幕）+ B（适配） | 有字幕时 3，无字幕时 2 |
| 素材 | 仅 B（图片为主，A 暂不支持） | 最多 2 |
| 备课综合 | A（教学设计）+ B（适配） | 最多 3 |
| 假期作业 | A（内容/考点）+ B（适配）+ C（出同类练习） | 最多 4 |
| 专辑 | A（合集主题聚合）+ B（适配） | 最多 3 |

## 6. 工程依赖与上线前提

| 依赖项 | 说明 | 阻塞哪类问题 |
| --- | --- | --- |
| 资源正文文本解析与存储 | PDF/Word/PPT 解析、存入检索库 | 阻塞 A 类所有问题 |
| 视频字幕/转写文本 | 视频转写 ASR 或现有字幕 | 阻塞音视频 A 类 |
| 用户记忆系统 tags 写入 | 记忆系统需真实建立，非 mock | 阻塞 B 类问题 |
| 消息来源标记（source 字段） | 区分资源详情问题与普通搜索 | 阻塞所有问题（防误触发搜索） |
| 资源类别字段对齐 | 前后端资源类别字段名和值统一 | 阻塞问题列表生成逻辑 |

> ⚠️ **MVP 建议**：先只上 A 类的"总结考点/教学重点"（全文本资源），和 C 类 handoff（出卷子）。B 类等记忆系统就绪后再上；"这道题怎么讲"需要先解决指定题目定位逻辑，放二期。

## 7. 设计决策记录

以下问题已确认，归档备查。

| 问题 | 决策 |
| --- | --- |
| 来源标记字段实现方式 | 产品层设计为消息体字段（`source: "resource_detail"`），具体实现（header 还是消息体）由开发决定 |
| 正文文本解析时机 | 首次实时解析 + 结果缓存；上线后需测试首次耗时，必要时改离线预处理 |
| 专辑子资源展示方式 | 专辑详情页只展示专辑级问题；子资源独立，点击进入子资源详情后按该资料类型展示问题 |
| 引用卡片样式 | 独立引用块，出现在消息气泡上方 |
| C 类 handoff 草稿保留 | 草稿保留为未完成态；入口显示在左侧对话消息下方，与 round 回看入口样式一致 |
