06建议处理优先级

优先级事项理由
P0 · 建议本周把 §1 七项修复固化为回归清单，每次原型改动后人工过一遍这类「改 A 坏 B」已发生多次，成本最低的止损手段。
P1 · 影响演示口径① 意图识别路径的出卷子登录拦截；② 登录后「回到触发前操作」补全（下载/导航路径）；③ 找资源冷启动分类卡改为教学场景分组都是给客户/老师演示时容易被问到的主流程。
P2 · 策略待澄清① 空结果「逐级放宽」去留（PRD 内部自相矛盾）；② 5 轮对话登录触发是否进原型；③ N=3 自动回首页是否进原型先由产品拍板，再决定是否投入原型实现。
P3 · 可后置手动添加记忆、学期切换提醒、placeholder 记忆个性化、埋点后端依赖强或演示价值低。
